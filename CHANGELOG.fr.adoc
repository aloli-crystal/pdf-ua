== v0.1.1 — 2026-06-02 — Sortie PDF/UA-1 certifiée veraPDF

=== Vérifié

* Un document construit avec `PDF::UA::Document` (titre + langue +
  structure taguée avec marked content via `page.tag`, police
  TrueType embarquée) est déclaré **`isCompliant="true"`** par
  **veraPDF 1.30.1** sur le profil PDF/UA-1 : 106 règles passées, 0
  échec.
+
RÉSERVE : veraPDF valide le sous-ensemble *vérifiable par machine*
  de PDF/UA-1 (les checkpoints automatisables du Matterhorn
  Protocol). Un passage veraPDF propre signifie aucun échec
  automatisé ; la conformité PDF/UA complète exige encore une revue
  humaine des checkpoints non automatisables (pertinence du texte
  alternatif, ordre de lecture logique, etc.). Résultat fort, pas un
  certificat complet.

=== Modifié

* Contrainte passée à `pdf ~> 0.7.6`.

== v0.1.0 — 2026-06-02 — Bootstrap (J4, palier 1)

=== Ajouté

* Couche initiale de profil d'accessibilité PDF/UA au-dessus de
  `aloli-crystal/pdf` (nécessite pdf ~> 0.7.5).
* `PDF::UA.configure(doc)` — déclare l'identification pdfuaid
  (`pdfua_part = 1`) et active `display_doc_title`.
* `PDF::UA.violations(doc)` — vérifications niveau document : non
  taggé, langue manquante, titre manquant, DisplayDocTitle
  désactivé, pdfuaid manquant — chacune tracée à sa clause
  ISO 14289-1.
* `PDF::UA.conformant?(doc)`.
* `PDF::UA::Document` — s'auto-configure à la construction et, en
  mode strict (défaut), lève `PDF::UA::ConformanceError` au
  `write`/`save` si une précondition n'est pas remplie.
* Se compose avec `pdf-a` : un document peut être configuré pour
  PDF/A et PDF/UA à la fois.
